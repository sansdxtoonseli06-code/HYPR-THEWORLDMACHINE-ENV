# **HYPR-THEWORLDMACHINE-ENV**

Welcome to the tiling window manager based on the indie game Oneshot made as a personal project. Many of the configurations have been based on other github repositories and there are changes generated by AI, I will leave the details later.

https://github.com/user-attachments/assets/2fd9bafb-65c3-478e-a2a5-9c44a6ba95f7

# **COMPONENTS**

| Component | Software |
|-----------|----------|
| Distro | CachyOS (based on Arch Linux) |
| Tiling Window Manager | Hyprland (Wayland) |
| Status Bar | Waybar |
| Terminal | Kitty |
| Shell | Fish |
| Application Launcher | Rofi |
| Packages | Starship, Hyprshot, Waypaper, Hyprpaper, Neofetch, Hyprlight, Hyprlock, Hypridle, Lavat, cli-vis |
