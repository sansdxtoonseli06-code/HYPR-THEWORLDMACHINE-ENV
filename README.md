# **COMPONENTS**

| Component | Software |
|-----------|----------|
| Distro | CachyOS (based on Arch Linux) |
| Tiling Window Manager | Hyprland (Wayland) |
| Status Bar | Waybar |
| Terminal | Kitty |
| Shell | Fish |
| Application Launcher | Rofi |
| Packages | Starship, Hyprshot, Waypaper, Hyprpaper, Neofetch, Hyprlight, Hyprlock, Hypridle, Lavat, cli-vis |
