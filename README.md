# **HYPR-THEWORLDMACHINE-ENV**

Welcome to the tiling window manager based on the indie game Oneshot made as a personal project. Many of the configurations have been based on other github repositories and there are changes generated by AI, I will leave the details later.


# **COMPONENTS**

|--------|-----:|
| Distro | CachyOS (Based on Arch) |
| Tiling window manager | Hyperland (Wayland) |
| Status bar | Waybar |
| Terminal | Kitty |
| Shell   | Fish |
| Application Launcher | Rofi |
| All packages   | starship , Hyprshot, waypaper and hyprpape , neofetch , hyprligth,hyprlock,hypridle,lavat,cli-vis |
|--------|-----:|
